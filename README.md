**🎧 AI-Powered Audiobook Pipeline** turns scanned books into audiobooks using OCR, LLM-based text correction and text-to-speech.

```text
📄 Scanned book ──► 🔍 OCR (Tesseract) ──► 🧠 LLM correction ──► 🔊 Text-to-speech ──► 🎧 Audiobook
```
