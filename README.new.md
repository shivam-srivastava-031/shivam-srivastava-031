## About me

I'm a CS undergraduate from Lucknow who likes taking an AI idea all the way to something you can click on: the model, the API around it, and the interface people use. Most of my recent work is in Python: LLM tooling, NLP pipelines, and backend systems that need queues, retries and a real database.

- 🔭 **Building:** [Workflow Automation System](https://github.com/shivam-srivastava-031/Workflow-Automation-System), a Zapier/n8n-style orchestrator with an LLM node and a plain-English workflow builder
- 🧪 **Running:** a [fully local LLM stack](https://github.com/shivam-srivastava-031/Dev-Local_Llm) with RAG, a coding agent and automations, on a laptop CPU
- 🌱 **Learning:** system design and LLM integration
- 💬 **Ask me about:** FastAPI, React, RAG pipelines, Docker

- Live progress over Server-Sent Events in a zero-dependency web UI

`Python` `Gradio` `Kokoro-82M` `EasyOCR` `JavaScript` · [**Live demo →**](https://shivam-srivastava-031.github.io/Dev-audio/)

### [LinkedIn Post Bot](https://github.com/shivam-srivastava-031/Telegram_linkedin_post)

Send a topic on Telegram; get back a LinkedIn post and a matching graphic.

- Gemini writes the copy and a 1200×1200 SVG graphic, exported to PNG
- Every SVG is validated: static safety checks, then text layout measured in Chromium
- Swap API keys in chat; the bot probes the available models and builds a fallback chain

`Python` `Gemini API` `Telegram Bot API` `Docker`

- Augmentation reduced overfitting and lifted validation accuracy by about 8%
- Real-time webcam classification with OpenCV, under 300 ms per image

`TensorFlow` `Keras` `OpenCV` `Python`
